About

I'm a software engineer in Apple's IS&T Customer Systems group. My work spans Swift/XCUI automation, cross-system data integrity validation across distributed service pipelines, and behavioral testing of an LLM-based voice assistant. Before that I built a full-stack cloud application (AWS RDS, Cognito, IAM) as my academic capstone.

I work best digging into logs and data rather than relying on assumptions — tracing a bug back through a distributed pipeline until the root cause is undeniable. I like building systems and processes that make repeated work easier, and I'm comfortable picking up new tools on the job. Lately that's meant pairing traditional test automation with AI-assisted engineering workflows: using Claude Code to navigate unfamiliar codebases, draft and review test scripts, and keep work aligned with team conventions.
